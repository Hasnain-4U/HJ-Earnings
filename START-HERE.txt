1. XAMPP mein MySQL Start karo.
2. Agar database pehle se bana hua hai to schema dobara import karne ki zaroorat nahi.
3. backend/.env mein apni working MySQL settings rakho.
4. backend folder mein CMD:
   npm install
5. Admin account banane ke liye (sirf pehli dafa):
   (optional) npm run admin
6. Server:
   npm start
7. Browser:
   http://localhost:5000
8. Purani cache ho to Ctrl + F5.
